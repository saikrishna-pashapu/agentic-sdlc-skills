# Planning Checklist

## Product understanding
- [ ] Product type identified and classified
- [ ] Target users identified with brief personas
- [ ] Core problem or value proposition stated
- [ ] Success criteria defined
- [ ] Constraints documented

## Requirements
- [ ] Major user workflows listed
- [ ] Required pages/screens mapped with purpose
- [ ] Auth model and user roles clarified
- [ ] Admin/backoffice needs identified
- [ ] Integrations and external services listed
- [ ] Non-functional requirements noted (performance, security, accessibility)

## Architecture
- [ ] System architecture overview created
- [ ] Frontend page map with sections and components defined
- [ ] Backend domains identified with responsibilities
- [ ] API contracts outlined with request/response shapes
- [ ] Database entities and relationships defined
- [ ] Data ownership mapped to backend domains
- [ ] Infrastructure and deployment approach decided

## Design depth
- [ ] Page-level layout structures described
- [ ] Reusable components identified across pages
- [ ] States handled: loading, empty, error, success, no results
- [ ] Responsive behavior noted for each page
- [ ] Backend validation rules defined per domain
- [ ] Error handling strategy documented
- [ ] Background jobs identified if needed

## Delivery readiness
- [ ] Assumptions documented explicitly
- [ ] Open questions listed
- [ ] MVP scope boundary defined
- [ ] Task backlog created with acceptance criteria
- [ ] Dependency order established for tasks
- [ ] Deployment assumptions recorded
