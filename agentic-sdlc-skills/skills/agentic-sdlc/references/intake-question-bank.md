# Intake Question Bank

Use only the questions that materially reduce ambiguity.

## Product and user
- Who is the main user?
- Is this public-facing or internal?
- Is mobile support required from day one?
- What is the single most important workflow?

## Auth and roles
- Is authentication required?
- Which user roles exist?
- Is there an admin panel?

## Data and integrations
- What core entities exist?
- Are there external APIs or third-party services?
- Do users upload files?

## UX and content
- Which screens/pages are required?
- Is there a design style reference?
- Should the system research UI patterns or competitors?

## Backend and ops
- Do you want a single app or separate frontend/backend?
- Which database should be used?
- Do you need email, payments, notifications, background jobs, or analytics?

## Delivery
- Should we optimize for MVP speed or long-term architecture?
- Should we write tests immediately or after core flows work?
